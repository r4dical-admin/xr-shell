# Retired app reskin prototype

This directory preserves the former app-specific theme generator and semantic wrapping prototype for reference. XR Shell no longer loads these modules or generates per-app themes. Captured apps now use FX or Tint, both colored by the selected shell theme.

Existing `integration-profiles/*.json` files still retain any previously generated `xrTheme` field as historical data. Accessibility recording and profile inspection remain active, but no new app-specific theme is generated.
